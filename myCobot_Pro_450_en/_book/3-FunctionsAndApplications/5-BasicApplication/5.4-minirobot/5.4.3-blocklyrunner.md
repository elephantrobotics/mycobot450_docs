# BlocklyRunner

In the Program interface, select the BlocklyRunner function by the asterisk ( * ).

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_show.png" width="300" align="center"/>

After entering the BlocklyRunner function, it will first check if there are any published track files in the myStudio Pro production folder.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_select1.png" width="300" align="center"/>

If no published track files are found, an error message will be displayed. At this time, the red light on the end strip will flash for 1 second.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_no_file.png" width="300" align="center"/>

If a published track file exists, it will be displayed in the BlocklyRunner interface. You can select to play a published track file.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_select2.png" width="300" align="center"/>

After selecting a published track file, its status will be checked first.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_check_file.png" width="300" align="center"/>

If the file is normal, press the A key to start playback. <img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_playing.png" width="300" align="center"/>

**During playback, the current loop status of the track file will be displayed in the upper right corner of the screen. Gray indicates single loop playback, white indicates infinite loop playback, and the default is infinite loop playback.**

**Before the track file starts or stops executing, you can press the C key to access the menu options to delete the track file, perform single playback, or loop playback.** After deletion, the corresponding track file in the myStudio Pro production folder will also be deleted.

If you select single playback, playback will automatically stop after the track file finishes playing.


<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_play_once.png" width="300" align="center"/>

If you select loop playback, it will automatically restart after the track file finishes playing.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_play_loop.png" width="300" align="center"/>

Pressing the A button again while playing will pause playback.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_pausing.png" width="300" align="center"/>

Pressing the B button will stop playback.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.3-blockly_runner/5.4.3-blocklyrunner_stop.png" width="300" align="center"/>
