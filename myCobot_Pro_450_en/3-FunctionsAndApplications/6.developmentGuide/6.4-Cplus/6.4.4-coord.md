# Coordinate control 
Coordinate control allows the robotic arm to move to a specified point in a designated posture. It is divided into x, y, z, rx, ry, and rz. X, Y, and Z represent the position of the robotic arm head in space (this coordinate system is a Cartesian coordinate system), while rx, ry, and rz represent the posture of the robotic arm head at that point (this coordinate system is an Euler coordinate system).<br>
## Single parameter control
### Send single-parameter coordinates<br>
**WriteCoord(Axis axis, double value, int speed = DefaultSpeed)**<br>
Return value: None<br>
Parameter Description: Parameter 1: Coordinate number (Axis enumeration type, int: 1-6 (X-RZ)), Parameter 2: Coordinates (**X, Y, Z** value range **-300-300.00** unit mm **RX, RY, RZ**, value range **-180-180**), Parameter 3: Speed ​​(**0-100**), default is **30**<br>
Example：<br>
`mycobot::MyCobot::I().WriteCoord(mycobot::Axis::X, 10, 30);`
## Multi-parameter control
### Get all coordinates<br>
**GetCoords()**<br>
Return value: Coords type<br> 
Parameter description: None<br>
Example：<br>
`mycobot::Coords coords = mycobot::MyCobot::I().GetCoords();`
### Send all coordinates<br>
**WriteCoords(const Coords& coords, int speed = DefaultSpeed)**<br>
Return value: None<br>
Parameter Description: Parameter 1: Coordinates (**X, Y, Z** value range **-300-300.00** unit mm **RX, RY, RZ** value range **-180-180**)<br> 
Parameter 2: Speed ​​(**0-100**), default is 30<br>
Example：<br>

	mycobot::Coords goal_coords = { 5, 5, 5, 5, 5, 5 };
	mycobot::MyCobot::I().WriteCoords(goal_coords, 30);

## Complete use case
The following code snippet is the main entry point for the control program that controls the MyCobot robotic arm. In this program, the first step is to check if the controller is connected to the robotic arm. If the connection is successful, the program powers on the robotic arm and stops its current movement. Next, it acquires and outputs the current angle and coordinates of the robotic arm and attempts to move all joints to the specified target angle. The program continuously outputs the current angle information until the target angle is achieved. Finally, the program adjusts the angle of a specific joint and stops the robotic arm's movement after adjustment. If an error occurs during the process, the program catches the exception and exits.


	int main(int argc, char* argv[])
	try {
	    QCoreApplication a(argc, argv); //Create a QCoreApplication object to support the Qt event loop.
	
	    using namespace std::chrono_literals; // Introduce literals for time processing (e.g., 200ms).
	
	    // Check if the robotic arm controller is connected.
	    if (!mycobot::MyCobot::I().IsControllerConnected()) {
	        std::cerr << "Robot is not connected\n"; // If the connection fails, an error message will be output.
	        exit(EXIT_FAILURE); // Exit the program and return to the failure status.
	    }
	
	    std::cout << "Robot is connected\n"; // Output a message indicating a successful connection.
	
	    mycobot::MyCobot::I().PowerOn(); // Power on and start the robotic arm
	    mycobot::MyCobot::I().StopRobot(); // Stop all movements of the robotic arm
	
	    // Check if the robotic arm is moving and output its status.
	    std::cout << "Robot is moving: " << mycobot::MyCobot::I().IsMoving() << "\n";
	
	    // Get the current angles of each joint of the robotic arm
	    mycobot::Angles angles = mycobot::MyCobot::I().GetAngles();
	    std::this_thread::sleep_for(200ms); // Delay 200 milliseconds
	
	    // Get the current position coordinates of the robotic arm's end effector
	    mycobot::Coords coords = mycobot::MyCobot::I().GetCoords();
	
	    // Obtain the angles of each joint again.
	    angles = mycobot::MyCobot::I().GetAngles();
	
	    // Output the angles of each joint
	    std::cout << "[" << angles[mycobot::J1] << ", " << angles[mycobot::J2] << ", " 
	              << angles[mycobot::J3] << ", " << angles[mycobot::J4] << ", " 
	              << angles[mycobot::J5] << ", " << angles[mycobot::J6] << "]";
	
	    // Define a target angle array, where all joints move to 5 degrees.
	    mycobot::Angles goal_angles = { 5, 5, 5, 5, 5, 5 };
	    mycobot::MyCobot::I().WriteAngles(goal_angles); // Move the robotic arm to the target angle.
	
	    // Waiting for the robotic arm to move to the target position
	    while (!mycobot::MyCobot::I().IsInPosition(goal_angles, false)) {
	        angles = mycobot::MyCobot::I().GetAngles(); //Get the current angle
	        std::cout << "[" << angles[mycobot::J1] << ", " << angles[mycobot::J2] << ", "
	                  << angles[mycobot::J3] << ", " << angles[mycobot::J4] << ", "
	                  << angles[mycobot::J5] << ", " << angles[mycobot::J6] << "]" << std::flush;
	        std::this_thread::sleep_for(200ms); // Each loop is delayed by 200 milliseconds.
	    }
	
	    // Adjust the angle of joint J1 by 1 degree, at a speed of 5.
	    mycobot::MyCobot::I().JogAngle(mycobot::Joint::J1, 1, 5);
	    std::this_thread::sleep_for(5000ms); // Delay 5 seconds
	
	    mycobot::MyCobot::I().StopRobot(); // Stop all movements of the robotic arm
	
	    std::cout << "\n"; // Output a newline character
	    exit(EXIT_SUCCESS); // Exit the program normally
	
	} catch (std::error_code&) {
	    // Catch std::error_code exceptions and output the error message.
	    std::cerr << "System error. Exiting.\n";
	    exit(EXIT_FAILURE); // Abnormal exit program
	} catch (...) {
	    // Catch all other exceptions and output error messages.
	    std::cerr << "Unknown exception thrown. Exiting.\n";
	    exit(EXIT_FAILURE); // Abnormal exit program
	}
