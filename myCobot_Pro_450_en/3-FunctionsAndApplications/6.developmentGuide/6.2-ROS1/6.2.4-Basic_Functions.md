# Robot Arm Control

>> **Note: The `pymycobot` driver library must be version 4.0.8 or higher, and the main controller firmware must be version 1.4 or higher.**

## Pre-use Preparation

Before using the sample functions, please ensure that the following hardware and environment are complete:

- **Hardware**
  - MyCobot Pro 450 robot arm
  - Network cable (for connecting the robot arm to the computer)
  - Power adapter
  - Emergency stop switch (for safe operation)

- **Software and Environment**
  - Python 3.6 or later installed
  - The `pymycobot` library must be installed, with a version of 4.0.8 or higher (you can install or upgrade it using `pip install -U pymycobot`).
  - The main controller firmware version must be 1.4 or higher.
  - If you are using the myGripper F100 force-controlled gripper, you must set the communication mode to "Modbus" via the small screen on the gripper itself before use; otherwise, it cannot be controlled properly. For instructions on how to configure this, please refer to [Gripper Screen Control](https://docs.elephantrobotics.com/docs/myGripper-F100-cn/5-BasicApplication/5.1.html).
  - Ensure that the MyCobot Pro 450 is properly powered on and in standby mode.
  - **Note**: The Pro 450 server automatically starts upon powering on; no manual operation is required.

- **Network Configuration**
  - MyCobot Pro 450 default IP address: `192.168.0.232`
  - Default port number: `4500`
  - **Note**: PC The local network card IP address must be set to the same network segment as the robot (e.g., 192.168.0.xxx, where xxx is a number between 2 and 254 and must not conflict with the robot).
  - For detailed configuration instructions, please refer to the section on [Static IP Configuration](../../5-BasicApplication/5.3-myStudioPro/5.3.1-myStudioFirstUse.md).
  - Example:
    - Robot IP: `192.168.0.232`
    - PC IP: `192.168.0.100`
    - Subnet mask: `255.255.255.0`
    - DNS server: `114.114.114.114`

  - **Verification**: After completing the network configuration, execute the following command on the PC terminal. If data packets are successfully returned, the network connection is normal:

    ```bash
    ping 192.168.0.232
    ```

- **ROS Environment Setup**

- Before using this example, ensure you have completed the [ROS environment setup and ROS code update](./6.2.1-Environment_Setup.md).
- If you have already configured your environment by adding the necessary settings to `~/.bashrc` as described in that section, you can run the commands below directly in any new terminal. Otherwise, you must execute `source ~/catkin_ws/devel/setup.bash` in each new terminal before proceeding.

Open a command line and run:

```bash
roslaunch mycobot_pro_450 slider_control.launch

# If the end effector is equipped with a myGripper F100 force-controlled gripper, run:
```

If you want the actual robot arm to execute the plan synchronously, you need to open another command line and run:

```bash
# The default IP address of the Pro450 is "192.168.0.232" and the port number is 4500.
rosrun mycobot_pro450_moveit sync_plan.py
```

`sync_plan.py` reads the configuration used by the currently running demo; if a `gripper_controller` is present, it automatically synchronizes the gripper. Please ensure that you first launch the `demo.launch` file—configured to match your actual hardware—before executing the command mentioned above.

Once `sync_plan.py` has run successfully, you may proceed with basic path planning operations.

### Modifying Movement Speed

The playback speed of a MoveIt trajectory is determined by the **Velocity Scaling** and **Accel. Scaling** parameters in the RViz MotionPlanning panel; both are set to `0.10` by default. Higher values ​​result in faster trajectory playback for the model, which also increases the speed of execution on the actual robot.

The speed at which commands are sent to the physical robot is fixed at 25; there is no need to modify the source code. It is recommended to keep these values ​​at `0.10` initially, and only increase them gradually once you have confirmed that the motion is smooth.
