# ACT模仿学习训练训练案例--夹取多种水果
## 1.准备工作
### 1.1 准备材料
- MyCobot Pro 450 机械臂
- MyArm C650 机械臂
- 电脑（3080及以上版本显卡、Ubuntu 22.04及以上版本、ROS2）
- 顶部摄像头 Gemini2
- 腕部摄像头 myCobotPro 摄像头法兰
- 力控夹爪
- 顶部摄像头支架
- USB转type-C数据线

### 1.2 硬件连接
- 顶部摄像头连接到 电脑上
- 腕部摄像头连接到 电脑上
- 力控夹爪连接到 MyCobot Pro 450 的末端接口上
- 腕部摄像头连接在 MyCobot Pro 450 的末端上
- MyArm C650 通电后再用type-C数据线连接到电脑上
- 启动 MyCobot Pro 450 机械臂并启动系统中的客户端（若不会启动客户端请参考[机器人复合案例](7.1.md) ）
- 顶部摄像头支架连接顶部摄像头
    - 如下图所示

### 1.3 机械臂固件版本及模型框架版本

## 2.项目配置
### 2.1 项目拉取
- 项目网址：[https://github.com/elephantrobotics/ER-ALOHA/tree/lerobot_pro450_v0.4.2](https://github.com/elephantrobotics/ER-ALOHA/tree/lerobot_pro450_v0.4.2)
- 终端输入：git clone https://github.com/elephantrobotics/ER-ALOHA.git
- 将项目拉取下来后在文件夹内新建一个终端，输入： git switch lerobot_pro450_v0.4.2

### 2.2 配置对应接口
- 确定MyArm C650机械臂串口名称，终端输入：**ls /dev/ttyACM***  
- 给串口权限，终端输入：**sudo chmod a+rw /dev/ttyACM***（串口名称）
- 确定两个摄像头串口名称，依次接入摄像头并终端输入：**ls /dev/video***
- 给摄像头权限，终端输入：**sudo chmod a+rw /dev/video***（串口名称）

### 2.3 LeRobot环境搭建并初始化
- 创建虚拟环境
    - 在终端依次输入：
        - **conda create -y -n lerobot_pro450 python=3.10**
- 进入虚拟环境
    - 在终端输入：
        - **conda activate lerobot_pro450**
- 安装ffmpeg
    - 在终端输入：
        - **conda install ffmpeg -c conda-forge**
- 安装lerobot
    - 在终端输入：
        - **cd ~/lerobot_pro450**
        - **pip install -e .**
        - **pip install lerobot**


## 3.遥操性能验证
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-teleoperate \
        --teleop.type=myarmc650_leader \
        --teleop.port=/dev/ttyACM0 \
        --teleop.baudrate=1000000 \
        --robot.type=mycobot_pro450_follower \
        --robot.host=192.168.0.232 \
        --robot.port=4500 \
        --display_data=true \
        --fps=30 \
        --robot.cameras="{top: {type: opencv, index_or_path: 6, width: 640, height: 480, fps: 30},hand: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}"
    ```
    - ***注意：此处的/dev/ttyACM0为C650机械臂的串口号，index_or_path：6和index_or_path: 0分别对应/dev/video6和/dev/video0***

## 4.数据采集
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-record \
        --teleop.type=myarmc650_leader \
        --teleop.port=/dev/ttyACM0 \
        --teleop.baudrate=1000000 \
        --robot.type=mycobot_pro450_follower \
        --robot.host=192.168.0.232 \
        --robot.port=4500 \
        --display_data=true \
        --robot.cameras="{top: {type: opencv, index_or_path: 6, width: 640, height: 480, fps: 30},hand: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
        --dataset.repo_id=your_name/fruit-record-test \
        --dataset.num_episodes=100 \
        --dataset.single_task="Grab the fruit"
    ```
    - ***注意：次数采集100次数据集，且采集下来的数据集保存在~/.cache/huggingface/lerobot/your_name 文件夹下***

    - 使用命令行参数设置数据记录流（可在上述指令后添加）：  
        - --dataset.episode_time_s=60每集数据录制时长（默认：60秒）。  
        - --dataset.reset_time_s=60每集后重置环境的持续时间（默认：60秒）。  
        - --dataset.num_episodes=50需要录制的总集数（默认：50集）。  


    - 在录制一个片段（episode）时:
        - 按下右箭头键 -> 可提前退出，并进入环境重置（resetting the environment）阶段。  
        - 在重置环境时，按下右箭头键 -> 可提前退出，并进入下一个片段的录制。  
        - 按下左箭头键 <- 可提前退出并重新录制当前片段。  
        - 按下退出键 esc 可停止数据录制 

## 5.执行采集的数据集
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-replay \
        --robot.type=mycobot_pro450_follower \
        --robot.host=192.168.0.232 \
        --robot.port=4500 \
        --dataset.repo_id=your_name/fruit-record-test \
        --dataset.episode=0
    ```

    - ***注意:dataset.episode的值，需要和采集数据时的episode保持一致，此处0对应的是第1次采集的数据集***

## 6.可视化数据集
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-dataset-viz \
        --repo-id=your_name/fruit-record-test \
        --episode-index=30
    ```

    - ***注意：episode-index的值，需要和采集数据时的episode保持一致，此处30对应的是第31次采集的数据集***

## 7.训练模型
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-train \
        --dataset.repo_id=your_name/fruit-record-test \
        --policy.type=act \
        --output_dir=outputs/train/act_pro450_fruit_test \
        --job_name=act_pro450_fruit_test \
        --policy.device=cuda \
        --wandb.enable=false \
        --policy.repo_id=act_pro450_fruit_test \
        --steps=200000
    ```

    - ***注意：steps的值是指训练200000步，可根据需求自行修改。步数越多，训练时长相对越久。***

## 8.在机械臂上评估策略
- 在激活的虚拟环境下的终端中输入：
    ```python
    lerobot-record  \
        --robot.type=mycobot_pro450_follower \
        --robot.host=192.168.0.232 \
        --robot.port=4500 \
        --robot.cameras="{top: {type: opencv, index_or_path: 6, width: 640, height: 480, fps: 30},hand: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
        --robot.id=my_awesome_follower_arm \
        --display_data=true \
        --dataset.repo_id=your_name/eval_fruit-record-test \
        --dataset.single_task="Grab the fruit into the box" \
        --policy.path=outputs/train/act_pro450_fruit_test/checkpoints/last/pretrained_model \
        --dataset.push_to_hub=false
    ```

    - ***注意:policy.path是存放训练模型的路径，且在决策过程中，也会将它的行为作为数据集的形式记录下来，所以也是可以使用键盘中的←键、键盘的→键和键盘的Esc***
