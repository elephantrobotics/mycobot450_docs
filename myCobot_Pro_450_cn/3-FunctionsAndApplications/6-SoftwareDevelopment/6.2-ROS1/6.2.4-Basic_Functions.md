# 控制机械臂

>> **注意：pymycobot 驱动库版本需大于等于 4.0.8，主控固件版本需大于等于 1.4。**

## 使用前准备

在使用案例功能之前，请先确认以下硬件和环境准备齐全：

- **硬件设备**  
  - MyCobot Pro 450 机械臂  
  - 网线（用于连接机械臂与电脑）  
  - 电源适配器  
  - 急停开关（确保安全操作）

- **软件与环境**  
  - 已安装 Python 3.6 及以上版本  
  - 已安装 `pymycobot` 库，版本需大于等于 4.0.8（可通过 `pip install -U pymycobot` 安装或升级）  
  - 主控固件版本需大于等于 1.4  
  - 若使用 myGripper F100 力控夹爪，使用前请在夹爪小屏幕上将通信方式设为 Modbus，否则无法正常控制。设置方法见 [夹爪屏幕控制](https://docs.elephantrobotics.com/docs/myGripper-F100-cn/5-BasicApplication/5.1.html)。
  - 确保 MyCobot Pro 450 已正确接通电源，并处于待机状态  
  - **注意**：Pro 450 服务端会在设备上电后自动启动，无需手动操作  

- **网络配置**  
  - MyCobot Pro 450 默认 IP 地址：`192.168.0.232`  
  - 默认端口号：`4500`  
  - **注意**：PC 端需要将本机网卡 IP 设置为 **同一网段**（例如 `192.168.0.xxx`，`xxx` 为 2~254 之间的任意数，且不能与机械臂冲突）。 
  - 具体配置方式请查看 [静态IP配置](https://docs.elephantrobotics.com/docs/mycobot-pro450-cn/3-FunctionsAndApplications/5-BasicApplication/5.3-myStudioPro/5.3.1-myStudioFirstUse.html#%E9%9D%99%E6%80%81ip%E9%85%8D%E7%BD%AE) 章节内容。
  - 示例：  
    - 机械臂 IP：`192.168.0.232`  
    - PC IP：`192.168.0.100`  
    - 子网掩码：`255.255.255.0`
    - DNS服务器：`114.114.114.114`
  
  - **验证**：完成网络配置后，可在 PC 终端执行以下命令，若能成功返回数据包，则说明网络连接正常：  
  
    ```bash
    ping 192.168.0.232
    ```

- **ROS环境搭建**
  - 使用案例之前，需确保已完成 [ROS环境搭建以及ROS代码更新](./6.2.1-Environment_Setup.md)
  - 若已按该章节把环境写入 `~/.bashrc`，新开终端后可直接运行下文命令。否则每个新终端先执行一次 `source ~/catkin_ws/devel/setup.bash`。

## 1 滑块控制

打开命令行并运行：

```bash
# Pro450 默认ip地址为"192.168.0.232"，端口号为 4500。
roslaunch mycobot_pro_450 slider_control.launch urdf:=v2

# 如果末端配有 myGripper F100 力控夹爪，则运行：
roslaunch mycobot_pro_450 slider_control.launch urdf:=v2 gripper:=f100
```

它会**打开 rviz 和一个滑块组件**，你会看到类似下面的内容：

<img src =../../../resources/3-FunctionsAndApplications/6.developmentGuide/ROS/ROS1/rviz/slider.png
width ="800"  align = "center">

如果末端装有 myGripper F100 力控夹爪，则会看到以下界面：

### 修改运动速度

MoveIt 轨迹的播放速度由 RViz MotionPlanning 面板中的 **Velocity Scaling** 和 **Accel. Scaling** 决定，默认都是 `0.10`。数值越大，模型轨迹播放越快，真机同步也会跟着变快。

真机每次下发的速度已固定为 25，不需要修改源码。建议先保持 `0.10`，确认运动平稳后再逐步调高。
