5.1 系统使用说明

5.1 系统使用说明

系统概述

myCobot Pro 机器人控制系统（MCPro RCS）是一个专为工业自动化、教育培训和研发调试设计的智能操作系统。它让机器人控制变得简单、安全又高效，无论是工厂老师傅还是技术工程师都能轻松上手。

🌟 核心亮点

  • 精准控制：6轴机器人，运动精度可达±0.1毫米，就像一位经验丰富的老技师
  • 两种操作方式：电脑远程编程 + 现场按钮控制，满足不同场景需求
  • 极速响应：系统反应<5毫秒，实时指令不卡顿
  • 安全隔离：控制网络与互联网物理分离，就像给控制中心装了防爆门
  • 硬件兼容：基于RK3562主控和ESP32显示屏，无需额外设备投入

🏗️ 系统架构

系统采用分层解耦设计，各层级功能清晰、协同高效：

  • 应用层：包含 WebApp（myStudio Pro 适配）、MiniRobot（miniroboflow 适配）、Python API 与远程访问模块，提供用户交互入口。
  • 算法层：涵盖运动控制、轨迹规划、避障算法、正逆运动学等核心计算模块，保障机器人精密运动。
  • 系统层：负责安全管理、错误处理、日志记录与网络接口管理，是系统稳定运行的核心支撑。
  • 核心层：处理系统状态管理、通信中间件与机器人运动控制服务，响应速度达 100Hz 以上，运动延迟＜5ms。
  • 网络接口：分为 LAN1（控制网络）、LAN2/WLAN（互联网接入），实现本地实时控制与远程访问的灵活切换。

MiniRobot - 现场操作小助手

MiniRobot是设计的本地控制界面，就像机器人的“遥控器”。4个按钮+小屏幕，操作简单，无需电脑，离线也能用。

🎮 主要功能

1. 轨迹录制（记录机器人动作）

  • 手动拖动：直接拉着机器人手臂走一遍，自动记录轨迹
  • 按钮输入：用上下键调整坐标位置，精确到0.1毫米
  • 100%保存：录制完成后自动保存，不会丢失

2. 文件管理（管理录制的动作）

  • 查看列表：最多保存50个动作文件
  • 简单操作：重命名、删除、执行，一键完成
  • 快速响应：操作反应<1秒，不卡顿

3. 执行控制（运行录制好的动作）

  • 两种模式：单次运行 或 循环重复
  • 进度显示：屏幕显示执行进度条
  • 紧急停止：急停按钮，0.5秒内立刻停止

4. 状态查看（了解机器人状况）

  • 实时信息：显示位置、速度、负载等参数
  • 流畅刷新：每秒更新10次以上，信息实时

5. 基础设置（简单参数调整）

  • 速度调节：设置运行速度快慢
  • 安全参数：调整安全保护设置
  • 零位校准：一键恢复初始位置

6. 通信转发（连接其他设备）

  • 数据中转：通过UART/SPI连接传感器等设备
  • 延迟极低：转发数据只需≤10毫秒

🛠️ 使用场景

场景 操作 优势
快速示教 按钮录制轨迹 不用编程，5分钟学会
现场监控 查看运行状态 实时了解机器人状况
日常维护 零位校准 保持机器人精度
无网环境 离线操作 没网络也能正常使用

📱 硬件配置

  • 屏幕：2.4英寸显示屏（手掌大小）
  • 按键：4个物理按钮（上下确认返回）
  • 主控：ESP32芯片
  • 连接：UART、SPI接口

myStudio Pro - 电脑端全能工作站

myStudio Pro是电脑端的专业控制软件，功能全面，适合编程、调试和远程管理。就像给机器人配了一个“智能控制中心”。

💻 核心功能

1. 图形化编程（像搭积木一样编程）

  • 拖拽操作：从左侧拖出代码块，右侧拼接成程序
  • 丰富模块：运动控制、传感器、逻辑判断等
  • 实时检查：程序语法错误立即提示
  • 代码管理：保存、导出、版本管理

2. 3D轨迹规划（虚拟仿真+真实录制）

  • 仿真环境：3D界面中规划机器人动作
  • 拖动示教：在仿真中拖动机器人，记录轨迹
  • 精度保证：轨迹误差≤0.1毫米
  • 流畅预览：30帧/秒流畅仿真

3. 文件管理（云端+本地结合）

  • 上传下载：最大支持10MB文件
  • 分类管理：程序、轨迹分开管理
  • 回收站：删除文件保留30天，可恢复
  • 批量操作：支持多文件同时处理

4. 执行监控（实时监控运行状态）

  • 状态面板：显示位置、速度、负载
  • 控制按钮：开始、暂停、停止
  • 实时更新：每秒刷新1次以上

5. 固件与教程（系统升级+学习）

  • 一键升级：检测新版本，自动下载安装
  • 视频教程：内置操作指南和教学视频
  • 更新稳定：成功率99%
  • 快速加载：教程2秒内打开

6. 网络配置（远程访问管理）

  • 权限开关：控制谁能远程访问
  • IP白名单：只允许指定设备连接
  • 立即生效：配置修改无需重启

响应速度 ≤500ms 操作反应快

  • 管理员：远程配置系统、监控状态
  • 教师：机器人编程教学
  • 研发人员：新产品功能测试

网络端口介绍 - 安全又灵活的网络设计

我们设计了三个独立的网络接口，让控制流量和上网流量完全分开，既保证了控制安全，又方便远程访问。

🌐 三网分工（各司其职，互不干扰）

LAN1 - 控制专线（最安全）

🔒 专用控制网络
📶 静态IP地址（手动设置）
🚫 不连接互联网
🎯 只用于机器人控制

使用场景：控制器连接、实时指令、位置广播

LAN2 - 有线互联网

🌍 连接互联网
📡 DHCP自动获取IP（或手动设置）
🔑 默认远程控制关闭（需手动开启）
🔄 开启后可远程访问

使用场景：远程监控、软件升级、技术支持

WLAN - 无线互联网

📱 无线连接
📶 DHCP自动获取IP
🔑 默认远程控制关闭（需手动开启）
🔄 开启后可远程访问

使用场景：远程监控、软件升级、技术支持

🔧 端口配置表

端口号 协议 功能 实时性 默认网络
8000 TCP 主控制指令 高实时 仅LAN1
8001 UDP 100ms位置广播 中实时 仅LAN1
8002 UDP 10ms位置广播 超高实时 仅LAN1
8100 WebSocket Web控制 中实时 仅LAN1
9000 TCP Modbus控制 高实时 仅LAN1
8080 HTTP 管理界面 低实时 全部网络

🛡️ 安全机制

1. 权限开关控制

  • LAN2和WLAN的远程控制可以单独开关
  • 默认状态：两个都关闭（最安全）
  • 开启后：控制端口同时绑定到相应网络

2. 关键保护措施

  • 广播端口锁定：8001、8002端口永远只在LAN1使用
  • 强制认证：远程访问必须登录账号
  • IP白名单：只允许信任的设备连接

3. 故障自动恢复

  • 30秒自愈：网络故障自动恢复
  • 95%成功率：重连成功率高
  • 状态监控：实时显示网络连接状态

📋 网络配置建议

使用场景 推荐配置 优势
生产环境 LAN1控制 + LAN2监控 控制安全，可远程查看
调试环境 LAN1控制 + WLAN调试 移动设备灵活连接
教育环境 LAN1控制 + LAN2上网 学生编程，老师监控
演示环境 开启所有网络权限 方便展示和操作

串行端口介绍 - 连接工业设备的桥梁

系统提供两种工业标准接口，可以连接各种工业设备，让机器人与生产线无缝集成。

🔌 RS485接口（工业通信标准）

📊 基本特性

📡 通信标准：RS485差分传输
📏 传输距离：最长1200米（低速率时）
🔗 连接设备：最多32台（标准版）
🔄 通信方式：半双工（可收可发，但不能同时）

🛠️ 能做什么？

  1. 连接PLC：与自动化控制系统通信
  2. 读取传感器：温度、压力、位置传感器
  3. 控制设备：变频器、伺服驱动器等
  4. 数据采集：收集生产线实时数据

⚙️ 常用设置

  • 波特率：9600（常用）、115200（高速）
  • 数据位：8位
  • 停止位：1位
  • 校验位：无校验（常用）

🚗 CAN总线（汽车/工业控制级通信）

📊 基本特性

🚀 通信标准：CAN 2.0A/B
⚡ 传输速度：最高1Mbps（40米内）
🎯 拓扑结构：总线型（所有设备挂一条线上）
🛡️ 错误处理：自动检测和恢复

🛠️ 能做什么？

  1. 驱动控制：连接多个电机驱动器
  2. 扩展I/O：数字输入输出模块
  3. 协同控制：多轴机器人同步
  4. 状态反馈：设备实时状态监控

⚙️ 常用设置

  • 波特率：125k、250k、500k（常用）
  • 帧格式：标准帧（11位）或扩展帧（29位）
  • 工作模式：正常模式（收发数据）
