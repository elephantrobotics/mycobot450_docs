# MiniRobot使用指南

## 简介
MiniRobot是myCobot Pro 450机械臂的控制面板，提供了丰富的功能接口，方便用户直观地操作和监控机械臂。本文档汇总了MiniRobot的主要功能模块及其使用方法。

## 主要功能模块

### 1. 首次使用
机械臂上电后，MiniRobot会显示Logo并进入主界面。主界面默认显示机械臂的关节信息和静态IP信息。通过屏幕底部按键可切换显示不同信息：
- C键：显示坐标信息和静态IP
- D键：显示末端M8接口的输入输出状态
- A键：进入菜单界面（30秒无操作自动返回主界面）

### 2. 拖动示教功能 (DragTeach)
通过直观的拖动操作来录制和播放机械臂运动轨迹：
- Record：录制机械臂运动轨迹（最长120秒）
- Play：播放已保存的轨迹文件
- 支持RAM和Flash两种存储方式
- Flash中保存的轨迹可上传至Web端生产文件夹

### 3. BlocklyRunner功能
管理和执行通过Web端发布的轨迹文件：
- 自动检查Web端生产文件夹中的已发布轨迹
- 支持播放、暂停、停止操作
- 可设置单次循环或无限循环播放模式
- 支持删除已发布的轨迹文件

### 4. 快速移动功能 (QuickMove)
提供机械臂的精确移动控制：
- FreeMove（自由移动）：长按末端按钮可自由拖动机械臂
- JogMove（关节点动）：通过点动控制单个关节运动
  - 支持角度模式和坐标模式
  - 单步0.1°，长按连续运动

### 5. 零位校准功能 (Calibration)
用于校准机械臂各关节的零位位置：
- 选择需要校准的关节
- 使用A、B键调整关节位置
- 运动至校准位置后按下C键保存，关节角度将重置为0°

### 6. 版本显示功能 (Firmware)
显示机械臂的所有版本信息：
- RobotID：机械臂唯一标识符
- Screen：MiniRobot版本
- System：系统版本
- Soft：Web+后端+运动控制版本
- Tool：末端版本

### 7. 连接状态功能 (Connection)
查看机械臂的网络连接信息：
- 可选择不同网络接口
- 显示当前网络配置信息

## 操作注意事项
- 在自由移动模式下，电机制动器会松开，请务必注意安全
- 菜单界面30秒无操作会自动返回主界面
- 录制轨迹有最长时间限制（120秒）
- RAM中保存的轨迹在机器重启后会丢失

## 文件保存说明
- Web端生产文件夹：已发布的轨迹文件
- Web端测试文件夹：未发布的轨迹文件
- Flash保存会覆盖之前的文件，仅保留最新版本
