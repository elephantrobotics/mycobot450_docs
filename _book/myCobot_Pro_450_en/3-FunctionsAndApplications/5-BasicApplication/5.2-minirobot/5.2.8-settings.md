# Settings

Select the Settings function with the asterisk on the Program interface and press the C key to enter the Settings function.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings.png" width="300" align="center"/>




After entering the Settings function, you can select Pack Stance or Clear Error.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_packstance1.png" width="300" align="center"/>



In Pack Stance mode, the angle data of the robotic arm is displayed in real-time. Press and hold the C key to start packing (it will first return to zero and then execute the packing angle). **The robotic arm will move at this time, please be careful!**

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_packstance2.png" width="300" align="center"/>

After pressing and holding the C key, the yellow text at the bottom of the screen changes to "Packing...", indicating that it is packing, and you can release the key.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_packstance3.png" width="300" align="center"/>



Packing completion will display green text prompt "Finished!", and return to the settings page automatically after three seconds.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_packstance4.png" width="300" align="center"/>


Packing failure will display red text prompt "Failed!", and return to the settings page automatically after three seconds.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_packstance5.png" width="300" align="center"/>


Enter the Clear Error page. If the robotic arm is not in joint limit or singularity limit, it will prompt "No Errors."

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror2.png" width="300" align="center"/>

If any joint is outside the limit, it will prompt that it is in limit, and you can press the C key to return to zero to clear the limit error.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror3.png" width="300" align="center"/>



The white text prompts "Backing..." during the return to zero process.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror5.png" width="300" align="center"/>


Return to zero completion green text prompts "Finished!", and return to the settings page automatically after three seconds.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror6.png" width="300" align="center"/>

If the machine is in a singular point, it will prompt that it is in singularity, and you can press the C key to clear the singularity error.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror4.png" width="300" align="center"/>

Clear singularity completion green text prompts "Finished!", and return to the settings page automatically after three seconds.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror7.png" width="300" align="center"/>

Clear singularity failure will display red text prompt "Failed!", and return to the settings page automatically after three seconds.

<img src="../../../resources/3-FunctionsAndApplications/5-BasicApplication/5.4/5.4.8-settings/5.4.8-settings_clearerror8.png" width="300" align="center"/>
